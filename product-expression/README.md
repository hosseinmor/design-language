# Product expression

The shared Design System is the default. This section records intentional Product-level differences and shared Theme-context rules without duplicating the full system.

## Current guidance

- `brands/theme-context.md` — canonical Product × Appearance Theme model, scope, ownership, and Foundation participation
- `brands/brand-variants.md` — Product-specific Brand usage rules and examples
- `brands/product-overrides.md` — reviewed Product-specific exceptions when needed
- `experiences/` — approved expressive modes when they exist

Product business logic does not belong here. Runtime CSS/token implementation details belong in the relevant integration contracts.
