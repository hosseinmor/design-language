# Apply the system

Use this playbook when designing or implementing a product experience with the
existing Design Language.

1. Load `overview/design-language.md` and the relevant Product Knowledge area.
2. Select the smallest applicable component or pattern contract.
3. Load only unresolved visual, content, interaction, or accessibility rules.
4. Inspect Figma for exact construction and Karbon/Storybook for exact runtime
   behavior; do not infer one source from another.
5. If no reusable contract fits, raise a system-evolution proposal instead of
   silently creating a local variant.

This playbook stops at Design Language decisions. The Product Development
Harness owns planning, implementation orchestration, rollout, and release.
