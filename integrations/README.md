# Integrations

This directory records **live-source pointers, ownership, registration status, and integration gaps**. It should stay small and operational.

- `source-of-truth.md` — ownership, conflict, and live-source fallback rules
- `karbon.md` — boundary and future registration contract for Karbon code and Storybook
- `figma.md` — verified Figma file, variable architecture, stable component identities, and design-source rules
- `code.md` — runtime implementation source registration and current Code gap
- `storybook.md` — executable Storybook source contract and current registration gap
- `component-mapping.md` — Figma component identity ↔ runtime component/prop ↔ Storybook mapping registry
- `theme-initialization.md` — installed Theme readiness, Appearance resolution, first-paint, hydration continuity, and no-flash contract

Do not copy Figma, Storybook, generated code documentation, or exhaustive live values into this directory. Store stable pointers, ownership, mapping metadata, registration status, and known gaps only.
